# 🕓 TimeSnap: Real-Time Clock Viewer Extension🕓

## A minimal real-time clock + motivational quote viewer 🌟

## 📌 Features
 - ⏱️ Shows the current time in real-time (12-hour format)
 - 💬 Displays one motivational or love-themed thought per day with the writer's name
 - 🔁 Thought updates automatically every 24 hours
 - 📱 Responsive design
 - 💻 Works in all modern browsers
 - 🌐 Works in Chrome, Edge, and other Chromium-based browsers

## 🚀 Live Link
 - ### <b><em><a href="https://timesnap-real-time-clock.netlify.app/">TimeSnap</a></em></b>
  
## 🛠️ Built With
 - HTML
 - CSS
 - JavaScript
  
## 💡 How It Works
 - The clock uses JavaScript to get and update the time every second.
 - A list of thoughts is stored in a JSON file.
 - One thought is shown per day based on the current date.
